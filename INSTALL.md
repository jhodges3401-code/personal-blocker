# Personal Blocker v0.2.3

## Updating (from v0.2.3 on): one click
Double-click **Update Personal Blocker** (the desktop shortcut, or `Update Personal Blocker.cmd` in this folder).
It downloads the newest version, copies it into this folder and prints `old -> new`.
Chrome switches to the new version by itself within about a minute (or immediately when you click the extension icon).
The popup shows the version and says **Up to date** or **Update available - run Update Personal Blocker**.

Optional, once: double-click **Create desktop shortcut.cmd** to put the updater on your desktop.
If Windows shows "Windows protected your PC": click **More info -> Run anyway** (the files came from a download).

## If anything looks wrong (the one fallback)
`chrome://extensions` -> **Remove** Personal Blocker -> **Load unpacked** -> pick the `src` folder inside this folder.
YouTube and Twitch blocking turn on automatically.

## First-time install
Unzip somewhere permanent -> `chrome://extensions` -> Developer mode on -> **Load unpacked** -> pick `src`.
Keep this folder where it is: Chrome loads the extension from it and the updater updates it in place.
